# 投研数据系统 (Research Investment)

自动化投研数据管线，覆盖从数据采集、清洗、分析到报告产出的全链路。

## 架构

```
┌─────────────────────────────────────────────┐
│              产出层 (Output)                  │
│  每日简报 · 深度研报 · 实时预警 · 数据看板      │
├─────────────────────────────────────────────┤
│              分析层 (Analysis)                │
│  情绪分析 · 异常检测 · 个股诊断 · 行业对比      │
├─────────────────────────────────────────────┤
│              加工层 (Processing)              │
│  数据清洗 · 去重去噪 · 标准化 · 指标计算        │
├─────────────────────────────────────────────┤
│              采集层 (Collection)              │
│  财经新闻 · 行情数据 · 社区舆情 · 宏观指标      │
└─────────────────────────────────────────────┘
```

## 快速开始

```bash
pip install -r requirements.txt
python main.py                # 完整流程：采集→处理→简报
python main.py --collect-only # 仅采集数据
python main.py --report-only  # 仅生成报告
python main.py --source news  # 仅采集新闻
```

## 配置

编辑 `config/watchlist.json` 自定义关注标的和预警规则。

## 数据源

| 来源 | 类型 | 说明 |

| 东方财富 | 财经新闻 | 要闻快讯 |

| AKShare | A股行情 | 实时行情+宏观指标 |
